# Privacy Policy

**Last updated:** November 14, 2026

## About this app

MindSpark Studio is a personal automation tool. It uploads videos to the owner's own YouTube channel using the YouTube Data API. It is not offered to the public and is used only by its owner.

## Data we access

The app requests the `youtube.upload` permission. This is used only to upload videos to the owner's YouTube channel.

## Data we collect and store

- We do **not** collect personal information from any user.
- We do **not** sell, share, or transfer any data to third parties.
- OAuth credentials (client ID, client secret, refresh token) are stored privately as encrypted GitHub Secrets and are used only to authenticate uploads.

## Google API Services

The app's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Revoking access

Access can be revoked at any time from the Google Account permissions page: https://myaccount.google.com/permissions
