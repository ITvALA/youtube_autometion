# Hindi Voice Samples for KittenTTS

Is folder me aap apna koi bhi Hindi voice sample (5 se 30 seconds ki saaf audio) rakh sakte hain:
- File name: `hindi_sample.wav` ya `hindi_sample.mp3`
- KittenTTS automatically is sample ko detect karke voice clone / reference ke taur par use karega.

Agar koi custom sample file nahi hogi, toh KittenTTS built-in express Hindi/multilingual voice preset use karega.
